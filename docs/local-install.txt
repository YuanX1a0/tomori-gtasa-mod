企鹅高松灯 Tomori — 本地替换皮肤 2（maccer）模组
====================================================================

适用：GTA:SA 单机 / SA-MP 客户端 / open.mp 客户端（只改自己电脑，别人看不到）
包含：modloader/maccer.dff、modloader/maccer.txd（已是皮肤 2 对应的模型名）
      skin_id_model_map.txt（全部 312 个皮肤 ID → 模型名 对照表）


一、为什么文件叫 maccer
----------------------
GTA:SA 里皮肤 ID 2 对应的模型文件名是 maccer。
想替换某个皮肤 ID，只要把模型的两个文件改成"该 ID 对应的模型名"即可，
文件名就是游戏内部加载模型的钥匙。


二、安装方法 A：modloader（推荐，不改游戏原文件）
----------------------------------------------
1. 安装 modloader.asi（GTA:SA 的通用 mod 加载器，放入游戏根目录）
2. 把本包 modloader 文件夹里的 maccer.dff、maccer.txd
   放进游戏根目录的 modloader 文件夹（没有就新建一个叫 modloader 的文件夹）
3. 启动游戏即可，替换皮肤 2 的所有角色都会变成企鹅高松灯

优点：随时删掉这两个文件就还原，不需要备份 gta3.img。
若用 SA-MP / open.mp 客户端，modloader 同样生效。


三、安装方法 B：替换 gta3.img（不用 modloader 时）
-----------------------------------------------
1. 先备份 models\gta3.img（很重要，改坏了要还原）
2. 用 Alci's IMG Editor 或 IMG Tool 打开 models\gta3.img
3. 找到 maccer.dff 和 maccer.txd，用 Replace（替换）功能选择本包里的同名文件
4. 保存后进游戏

注意：dff 与 txd 必须成对替换，只换一个会变成灰白模型或崩溃。


四、换成本地任意角色 ID（教程）
----------------------------
核心只有一句话：把两个模型文件，改成目标皮肤 ID 对应的模型名。

步骤：
1. 打开 skin_id_model_map.txt，格式是：
       皮肤ID <Tab> 模型名
   例如：
       2      maccer
       280    lapd1
       281    sfpd1
       285    swat
       0      cj
2. 找到你想要替换的 ID，记下右边的模型名（比如 164 → wmyboun）。
3. 复制一份 maccer.dff、maccer.txd，分别重命名为：
       wmyboun.dff
       wmyboun.txd
   （扩展名保留 dff / txd，文件名大小写按表里写的原样）
4. 按第二节（modloader）或第三节（IMG）装进去。

示例：想同时替换 2（maccer）和 280（警察）
       modloader/maccer.dff + maccer.txd
       modloader/lapd1.dff  + lapd1.txd
   可以放任意多份，每个模型名一对文件。

如果对照表里没有你想要的 ID：到 SA-MP / open.mp 的皮肤列表页查
"Skin ID → Skin Model Name"，或直接看游戏 models\gta3.img 里的 ped 模型名。


五、注意事项
-----------
1. 只影响你自己的客户端；服务器上的其他玩家看到的还是原皮肤。
2. 服务器如果注册了自定义皮肤（AddCharModel，ID 20000 以上），那是服务端
   下发的模型，本地替换不了——那种情况需要服务器改 artconfig。
3. 替换标准皮肤会连带替换所有用到该模型的角色/NPC，属正常现象。
4. 本模型是标准男性 ped 骨架（32 骨），替换任意男性/女性皮肤都能正常
   动作；替换成极端体型（如胖子/瘦猴）动画会有轻微错位，属正常。
5. 本包模型已移除顶点色，不会出现"进游戏变黑"的问题。
